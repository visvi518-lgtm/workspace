# Momentum App

Vanilla JavaScript로 구현한 개인 대시보드 웹 앱입니다. 실시간 시계, 시간대별 인사말, To-Do 리스트, 랜덤 명언, 랜덤 배경 이미지, 현재 위치 기반 날씨 정보를 제공합니다.

## Tech Stack

- HTML
- CSS
- JavaScript
- LocalStorage
- Geolocation API
- OpenWeatherMap REST API

## Features

- 실시간 시계 및 시간대별 인사말
- 사용자 이름 저장
- To-Do 추가 및 삭제
- 랜덤 명언과 배경 이미지 표시
- 현재 위치 기반 날씨 정보 조회
- 반응형 UI

## Weather API Setup

`js/config.example.js`를 참고해 `js/config.js` 파일을 만들고 OpenWeatherMap API Key를 입력하면 날씨 기능을 사용할 수 있습니다.
